# TP7 - Serialization

## Objective

This TP explains how data can be serialized and deserialized using different formats.

It includes:

- JSON validation
- Secure XML parsing
- Binary encoding similar to Protobuf

## Files

- `json_validation.py`: validates and serializes JSON data.
- `secure_xml.py`: parses XML safely and rejects dangerous payloads.
- `binary_encoding.py`: encodes and decodes data in binary format.

## Concepts Used

- Serialization
- Deserialization
- JSON validation
- XML security
- XXE protection
- Binary encoding
- Payload size comparison

## How to Run

Run each file separately:

```bash
python json_validation.py
